# Дневник здоровья (Health Diary)

Приложение для Android (Kotlin, Jetpack Compose, Room). Подходит любому пациенту: можно вести
дневник давления, пульса, сахара, веса, температуры и кислорода, вносить показания с клавиатуры
или голосом, вести свой список лекарств и отправлять врачу текстовый отчёт через любой
мессенджер (Telegram, WhatsApp, MAX, почта и др.).

## Возможности

- **Таблица показаний.** Столбцы: дата (время мелким шрифтом под ней), время суток (утро, полдень, вечер, ночь), верхнее и
  нижнее давление, пульс, принятые лекарства с дозировкой, заметка, изменить, удалить.
  Единицы измерения только в шапке столбцов. Таблицу можно свайпать вправо и влево.
  Тип измерения выбирается сверху. Кнопка «Очистить» под таблицей удаляет сразу все записи
  выбранного типа (с подтверждением), чтобы не стирать накопленные данные по одной.
- **Голосовой ввод.** Значок микрофона справа в каждом поле ввода. В поле «Быстрый ввод»
  можно продиктовать фразу целиком: «давление 135 на 80 пульс 72», поля заполнятся сами.
- **Лекарства.** Тоже таблица (название, дозировка, когда принимать, заметка, изменить,
  удалить) с кнопкой «Очистить» под ней. Пациент сам заполняет список. При внесении показания
  отмечает, какие лекарства принял. В записи сохраняется название с дозировкой.
- **Верхняя панель и меню.** Вверху название приложения и сведения о текущей вкладке. Меню с
  тремя точками: новое показание, отправка врачу, инструкция, настройки, о приложении.
- **Вид показаний.** Тип измерения выбирается из выпадающего списка. Переключатель «Карточки / Таблица» в одной рамке над списком (выбор запоминается).
  Карточки идут по дням (Сегодня, Вчера, дата): крупное значение, цветная полоса статуса
  (зелёная, жёлтая, красная; это подсказка по общим границам, а не диагноз), время суток и время,
  пульс, принятые лекарства, заметка. Таблица с боковым свайпом осталась как второй вид; таблицы показаний и лекарств оформлены как таблица для врача (цветная шапка, полосатые строки, текст по центру).
- **Оформление.** Собственная палитра (бирюзовый и синий), градиентная шапка, крупные скругления,
  кнопки-таблетки. Утро / Полдень / Вечер / Ночь собраны в одну рамку. Нижняя панель обычная,
  со своими векторными значками.
- **Кнопки.** Все кнопки выглядят как «Утро / Вечер» (чипы): выбранная закрашена.
- **Отправка врачу.** Отчёт за 7, 14, 30 дней или за всё время (период выбирается в одной рамке, активный закрашен и с галочкой): лекарства, показания по датам,
  среднее давление. Отчёт сделан таблицами: отдельная таблица лекарств и таблица на каждый тип измерения, где у каждого
  значения своя колонка (для давления: верхнее, нижнее, пульс; единицы в заголовках), затем лекарства
  и заметка, если они есть. Только внесённые значения, без вычислений (средних и т. п.). Врачу уходит PDF с настоящей таблицей;
  есть и вариант текстом для чатов, где файл не открыть, а также копирование. Отправка через стандартное меню «Поделиться».
- **Настройки.** Тема и язык (выпадающие списки, названия над ними), экспорт и импорт всех данных в файл JSON
  (при импорте текущие данные заменяются после подтверждения; чужой файл ничего не меняет),
  инструкция пользователя.
- **Ориентация.** Приложение работает только в портретном положении, экран не поворачивается.
- **Оценка приложения.** На 10-м открытии, затем через каждые 50 (60-е, 110-е и т. д.) показывается
  окно со звёздами, пока пользователь не поставит оценку. 4 и 5 звёзд открывают страницу
  приложения в RuStore, 1–3 звезды открывают письмо разработчику (vl.profits@gmail.com).
  Кнопка «Позже» закрывает окно до следующих 50 открытий. После оценки окно больше не появляется.
- Данные хранятся только на телефоне, доступа в интернет у приложения нет.
- Приложение не даёт медицинских советов.

## Как собрать

1. Android Studio: File > Open, выберите папку проекта и дождитесь Gradle sync
   (нужен интернет, Gradle 8.7 скачается сам).
2. Запустите на телефоне или эмуляторе (minSdk 24, Android 7.0 и новее).
3. Пространство имён и `applicationId` — `com.semenenko.healthdiary` (`app/build.gradle.kts`).
   Ссылка на страницу в RuStore строится из него: `rustore.ru/catalog/app/<applicationId>`.
4. Иконка приложения (серая, белое сердце с линией пульса) уже есть: адаптивная в
   `res/drawable/ic_launcher_foreground.xml` и `res/mipmap-anydpi-v26/`, одноцветная для
   тематических иконок Android 13 в `ic_launcher_monochrome.xml`, обычные PNG в
   `res/mipmap-*dpi/`. Заменить её можно через правый клик на `res` > New > Image Asset.

## Голосовой ввод

Кнопка микрофона открывает системное распознавание речи. Если его на телефоне нет,
используйте микрофон на клавиатуре. В текстовых полях сказанное дописывается к уже введённому
тексту, с большой буквы только в начале поля и после «.», «!», «?»; продолжение предложения остаётся с маленькой; крестик справа стирает поле.
В числовых полях берётся первое число из сказанного и заменяет значение.
Числа можно называть цифрами или словами: «сто тридцать пять» даёт 135. Дробные значения
(сахар, вес, температура): «пять запятая пять», «пять и пять» или «5 и 5» дают 5,5.
В поле «Быстрый ввод» название измерения можно не говорить, если тип уже выбран сверху:
для сахара достаточно «четыре запятая два».

## Структура

- `data/` — таблицы Room, DAO, база данных (версия 2, есть миграция с версии 1)
- `voice/SpokenNumber.kt` — числа словами и «запятая» в цифры
- `voice/VoiceParser.kt` — разбор фразы в показание
- `report/ReportBuilder.kt` — текст отчёта для врача
- `ui/` — экраны Compose: показания (таблица и форма), лекарства, отправка, настройки
- `ui/RatingDialog.kt`, `util/Rating.kt` — окно оценки и правила его показа
- `util/` — форматы, проверка ввода, настройки темы и языка
- `res/values/` — английские строки, `res/values-ru/` — русские
- `res/drawable/ic_tab_*.xml` — векторные значки нижних вкладок (блокнот, капсула, исходящие, шестерёнка), их можно заменить
